# Sistema global de cores e animações

## Cores principais
- **Cor 1** → topo da tela
- **Cor 2** → centro (estado A)
- **Cor 3** → centro (estado B) + parte inferior
- **Cor 4** → elementos animados (queda do topo)

## Alternância Cor 2 ↔ Cor 3
- Alternância automática
- Transição suave (animação)
- Estado persistido localmente (configs)

## Elementos animados
- Tipos simples: flocos, cubos, pontos
- Opção de ativar/desativar
- Cor baseada na Cor 4
- Recomendado manter desempenho leve (quantidade ajustável)
