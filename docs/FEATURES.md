# Features detalhadas

## Menu principal
- Botões grandes (cards gamer):
  - 🎮 Gamer
  - 📅 Calendário
  - 🎵 MP3 / MP4
  - 📝 Anotações
  - 🎨 Personalizar App
  - 👤 Perfil/Login (local)

## Perfil/Login local
- Cadastro com **nickname obrigatório**
- Nick único (bloquear duplicado)
- Foto de perfil, bio curta, cor personalizada
- Sistema de tags
- Se nickname for exatamente `Bernkzz`, aplicar tag **ADM** automaticamente

## Menu Gamer
- 🕹️ Jogos
- 🧩 Quebra-cabeça
- ⭐ Atalhos Gamer
- 🧠 Configurações de jogos

### Jogos (offline)
- Estilo Dino
- Flappy Bird
- Pong
- Breakout
- Outros simples similares

Configurações possíveis quando aplicável:
- Velocidade
- Gravidade
- Força do pulo
- Tempo de pulo
- Dificuldade
- Invencibilidade (opcional)

Regra: **não alterar jogos “sagrados” com hacks/cheats**.

### Quebra-cabeça (Puzzle)
- Importar imagem do celular
- Definir dificuldade (quantidade de peças)
- Embaralhamento realmente aleatório
- Encaixe inteligente (hitbox)
- Peças corretas se unem
- Mensagem final: **“Parabéns! Tu conseguiu!”**

### Atalhos Gamer
- Criar atalhos para apps/jogos instalados
- Cada atalho contém: nome, ícone, categoria

## Calendário
- Offline
- Criar eventos com nome, descrição, foto, cor personalizada
- Visual mensal e semanal

## MP3/MP4
- Sistema de mídia interno baseado em pastas
- Pastas padrão: Músicas, SFX, Vídeos
- Botão flutuante (+):
  - Fora de pasta → criar nova pasta
  - Dentro da pasta → importar MP3/MP4

## Anotações
- Offline
- Organização por pastas
- Nota contém: título, texto livre, cor, data

## Personalizar App
- Presets visuais
- Padrões personalizados
- Paleta de cores
- Tipo de elementos animados
- Aplicação global do tema

## IA Offline (limitada)
- Sugestão de cores
- Organização de conteúdo
- Auxílio em configurações
- **Sem processamento online**
